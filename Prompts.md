# AI Prompts Used During Development

AI tools were used during development for guidance, debugging, and design suggestions. The main implementation and integration were done manually.

## Prompts Used

### 1. Responsive Design
"How can I make my HTML/CSS landing page responsive for desktop and mobile?"

### 2. Mobile Navigation
"How can I implement a hamburger menu for the mobile navbar using JavaScript?"

### 3. Dark Mode
"How can I add a dark mode toggle using JavaScript and CSS?"

### 4. UI Improvement
"Suggest some improvements to make my landing page cleaner and more professional."

### 5. Deployment & Documentation
"How can I deploy my HTML, CSS and JavaScript project using GitHub and Vercel?"
